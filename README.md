# bdstorage

个人项目与配置归档。

## 内容

| 目录 | 说明 |
|---|---|
| [`hermes-ui-bd/`](hermes-ui-bd/) | **HermesUI-BD定制** — Hermes 桌面端单文件主题插件（深蓝配色 + 底栏状态条 + 聊天区增强）。安装见目录内 README |
| [`手机提醒上课小部件/`](手机提醒上课小部件/) | Android 课表提醒小部件（Kotlin + Jetpack Compose） |

## hermes-ui-bd 快速开始

```bash
# 1. 复制到 Hermes 的桌面插件目录（目录名必须是 hermes-ui-bd）
cp -r hermes-ui-bd ~/hermes/desktop-plugins/

# 2. 重启 Hermes 桌面端
# 3. 插件列表里启用「HermesUI-BD定制」，外观里选择「深蓝主题 V3.4（BD）」
```
