# 文件格式转换助手 · 迁移部署安装文档

> 本文件面向需要把工具部署到新电脑（迁移）或安装后管理维护的人员。
> 只想用工具请看《使用说明.md》。

## 一、交付物清单

收到本压缩包解压后，应有以下内容：

```
文件格式转换助手/
├── 使用说明.md               # 终端用户使用说明
├── 迁移部署安装文档.md         # 本文档
├── README.md                 # 项目简介（开发与维护视角）
├── dist/
│   └── 文件格式转换助手/        # 程序本体（整体迁移，不可拆散）
│       ├── 文件格式转换助手.exe  # 双击运行
│       ├── _internal/          # 运行库与依赖（PyInstaller onedir 结构）
│       └── …其他运行文件
└── tests/                    # 自动化验收脚本（开发者维护用）
```

**zip 总大小约 200MB（程序本体约 385MB，压缩后约 200MB）。**

## 二、目标环境要求

| 项目 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10 / 11（64 位） | 已验证 Windows 11 |
| 架构 | x64 | 程序为 x64 构建 |
| 运行 Python | **不需要** | exe 已内置运行环境，目标机无需安装 Python |
| Word→PDF 功能 | 本机需安装 **Microsoft Word 或 WPS** | 无则此项不可用（有明确提示），PDF→Word 不受影响 |
| 磁盘空间 | 至少 1GB 空闲 | 程序本体约 385MB |
| 网络 | 不需要 | 纯本地运行，不联网 |

## 三、部署步骤（三步完成）

### 第 1 步：拷贝

把整个 `dist\文件格式转换助手\` 文件夹**原样**复制到目标机任意位置
（如 `D:\Tools\文件格式转换助手\`）。**务必整个文件夹一起拷贝**，不要只拷 exe。

> 注：PyInstaller onedir 模式下，exe 依赖同目录 `_internal` 及周边文件，
> 单独移动 exe 会导致程序无法启动。

### 第 2 步：验证运行

双击 `文件格式转换助手.exe`，看到主窗口、底部状态栏显示
"就绪　|　转换引擎：Word、WPS"（或部分引擎名）即为启动成功。

> 首次运行如被 Windows 提示"更多信息/仍要运行"，属 SmartScreen 对未签名
> 程序的安全提示，点击"仍要运行"即可（本程序为本地开源构建，无网络行为）。

### 第 3 步：功能冒烟验证（建议）

拖入一个 `.docx` 与一个 `.pdf`，点"开始转换"，确认：
1. 两个文件分别显示 ✔ 成功；
2. 源目录出现同名反扩展名的新文件；
3. 打开输出文件内容正确。

## 四、常见部署问题排查

| 现象 | 原因与处理 |
|---|---|
| 双击无反应 | 检查是否只拷了 exe 而非整个文件夹；查看是否有杀毒软件拦截，加入信任或白名单 |
| 提示"未检测到 Word/WPS" | 目标机未装 Office/WPS。安装 Word 或 WPS 后重启程序；仅用 PDF→Word 则无需理会 |
| Word→PDF 一直失败 | 确认 Word/WPS 为已激活的正常版本；程序会先在 Word 失败后自动回退 WPS 重试 |
| 中文路径乱码 | 本程序已内置中文字体处理，正常使用中文路径；如个别系统异常，先检查目标机系统字体 |

## 五、卸载与清理

- 直接删除 `dist\文件格式转换助手\` 文件夹即可完成卸载
- 程序**不写入注册表、不创建开机启动项、不留用户数据**，删除即干净
- 转换输出文件由用户自行保留，卸载不影响

## 六、开发与维护（可选）

如需修改程序或重新打包，需 Python 3.10+ 环境：

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt -r requirements-dev.txt
.venv\Scripts\python src\main.py            # 源码运行
.venv\Scripts\pyinstaller --noconfirm --clean --onedir --windowed ^
    --name 文件格式转换助手 --distpath dist --workpath build ^
    --specpath . src\main.py                # 重新打包
```

自动化验收：

```bash
.venv\Scripts\python tests\m1_core_test.py   # 核心服务层用例
.venv\Scripts\python tests\m2_ui_test.py     # 界面整合用例
```
