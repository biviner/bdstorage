# 文件格式转换助手 · 使用说明

> 适用于拿到压缩包、只想用工具的人。安装方法见《迁移部署安装文档.md》。

## 一、这个工具能做什么

| 转换方向 | 效果 |
|---|---|
| Word（.docx）→ PDF | 调用本机 Word/WPS 转换，效果与手动"另存为 PDF"一致 |
| PDF → Word（.docx） | 内置引擎转换，段落、表格、图片尽力还原，转出后**可编辑** |

- 支持**批量**：一次拖入多个文件，逐个转换
- 转换结果保存在**源文件所在目录**，文件名相同、扩展名替换（如 `报告.docx` → `报告.pdf`）
- 文件**完全在本地处理**，不上传任何内容到网络

## 二、怎么用（三步）

1. **双击运行** `文件格式转换助手.exe`（在 `dist\文件格式转换助手\` 目录里，文件夹整体不能分开）
2. **把文件拖进窗口**，或点击"选择文件"
3. 点击 **"开始转换"**，等列表全部完成

转换过程中每个文件都会显示状态：

| 状态 | 含义 |
|---|---|
| ✔ 成功 | 已完成，可点击"打开位置"查看输出文件 |
| ⟳ 转换中… | 正在处理 |
| ⚠ 跳过：… | 无法转换，原因见后面的文字 |
| ✖ 失败：… | 转换出错，原因见后面的文字 |

## 三、常见问题

**Q1：Word→PDF 提示"需本机安装 Office/WPS"？**
Word→PDF 必须借用本机已安装的 Microsoft Word 或 WPS 才能转换。请安装其中任意一个后重启程序。

**Q2：为什么 PDF 转 Word 后有些内容是图片、不能编辑？**
源 PDF 里本身就是图片的内容（扫描件、截图、公式图片）转出后仍是图片。这是所有同类工具的共性边界，程序对此无法"识别成文字"（除非做 OCR，本工具暂不支持）。

**Q3：PDF 提示"扫描版 PDF，无法转为可编辑文字"？**
该 PDF 整页是扫描照片、没有文字层。程序已检测到并跳过，不做 OCR。

**Q4：提示"加密文件暂不支持"？**
带密码保护的文件无法转换，请先解密再转换。

**Q5：转换失败"文件损坏或无法读取"？**
文件可能已损坏或格式被改过扩展名。请确认文件能正常打开。

**Q6：输出文件重名了？**
不会覆盖已有文件。同名会自动加序号：`报告.pdf` 已存在时输出 `报告 (1).pdf`。

**Q7：Word 打开转出的 docx，再"导出 PDF"失败？**
这是 Word 对复杂 docx 的已知限制（pdf2docx 生成的文档）。**如需把这类 docx 再转回 PDF，请继续用本工具**——它会自动改用 WPS 引擎，转换正常。

## 四、注意事项

- `dist\文件格式转换助手\` 是一个整体，**移动、拷贝时要整个文件夹一起**，exe 不能单独拿出来运行
- 程序关闭即不留任何历史记录（无日志、无缓存），符合隐私设计
- 转换大文件（几十页 PDF）期间窗口会等待，属正常现象，请勿重复点击
