# 智能课表（手机提醒上课小部件）

一款面向学生的 Android 课表工具：课表截图一键识别导入，桌面小组件常驻显示下一节课和今日课程，上课前自动提醒。本地运行，无账号、无服务器。

## 安装

1. 从 `release/` 取 `timetable-0.1.0-release.apk`（Android 8.0+）。
2. 手机上直接安装（需允许安装未知来源应用）。
3. 首次进入按引导：设置学期起始日 → 导入课表 → 授权通知 → 添加小组件。

## 从桌面添加小组件

- 长按桌面空白处 → 小组件/部件 → 找「智能课表」：
  - **2×2 下一节课**：显示下一节课名称/时间/教室/倒计时，点击进课程详情。
  - **4×2 今日课程**：显示今天日期与全部课程（进行中高亮、已结束半透明），点击进首页。

## 配置识别服务（导入课表前必做）

1. 打开 App → 设置 → 识别服务。
2. 填三项：
   - **Base URL**：OpenAI 兼容接口地址（如 `https://api.deepseek.com/v1`，必须带 `http(s)://`）。
   - **API Key**：你的密钥（仅存本机，不进日志）。
   - **模型名**：支持图片输入的模型（如 `deepseek-vl` 类，或任何视觉模型）。
3. 首次导入时会提示「图片将上传至你配置的识别服务」，确认后才发起网络请求。

## 权限与提醒可靠性

- **通知权限**（Android 13+）：首次进入首页会请求，拒绝后顶部有横幅可再次授权。
- **精确闹钟**（Android 12+）：设置页显示授权状态，未授权时点击跳系统设置开启——这保证上课提醒准点。
- **国产 ROM（小米/华为等）**：建议在系统设置里把本应用加入电池优化白名单/自启动，否则精确闹钟可能被系统回收（应用内有每日兜底重排，但可能延迟几分钟）。

## 日常使用

- 周课表页可翻周、查看任意教学周；课程点击可编辑（时间/周次/教室/颜色/提醒/停课日期）。
- 支持单双周与不连续周次（如 1-8、10-16 周）。
- 修改任何课程后，小组件与提醒自动同步，无需重启。

## 隐私

- 课表数据全部存本机；唯一网络请求是图片识别，且每次上传前明示。
- 无账号、无遥测、无云同步。
