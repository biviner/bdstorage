## 使用方式

在项目根目录执行：

```bash
source tools/env.sh
```

之后 `JAVA_HOME` / `ANDROID_HOME` / `PATH` 即就绪（均指向 `tools/` 内路径）。

注意：git-bash(MSYS2) 的 `PATH` 按 `:` 分隔，条目里的 `D:` 会被截断，
故 `env.sh` 中 `JAVA_HOME`/`ANDROID_HOME` 用 `D:/` 形式、`PATH` 条目用 `/d/...` 形式，
两者在 git-bash 与 Gradle/原生进程下均工作正常。
