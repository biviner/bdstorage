## 四、发现清单

**[MEDIUM] CustomWeeks.decode 区间展开无上界，存在 OOM 风险**
文件： `core/domain/src/main/kotlin/com/zjh/timetable/domain/calc/CustomWeeks.kt:51`
Issue: `for (week in minOf(a,b)..maxOf(a,b))` 对区间长度无上限。`weeksRaw` 来自 B3 识别网关的模型输出（非可信输入），模型幻觉出 `"1-2000000000"` 这类 token 时会一次性向 `sortedSetOf` 塞入 20 亿个 Int 装箱对象，直接 OOM 崩溃。设计规定“超界周次保留由上层过滤”，但保留不等于无界物化。
Fix 建议（供批次 3 实现方采纳，B1 期间可先记录）：区间跨度超过阈值（如 100 或 `totalWeeks` 上界）时丢弃该 token 并记入 warnings，语义与“非法 token 丢弃并附 warning”一致。附带单测：`decode("1-999999999")` 不崩溃。

**[LOW] PeriodMapper 存在未使用 import**
文件： `core/domain/src/main/kotlin/com/zjh/timetable/domain/calc/PeriodMapper.kt:3`
Issue: `import com.zjh.timetable.domain.model.Course` 未被使用（该文件仅消费 `PeriodTime`）。
Fix: 删除该行（改动仅此一行时顺带处理，不阻塞）。

**[LOW] WidgetText 倒计时字段使用字符串拼接而非模板**
文件： `core/domain/src/main/kotlin/com/zjh/timetable/domain/text/WidgetText.kt:76`
Issue: `"距上课还有 " + countdownText(minutes)`，同文件其余处均为字符串模板风格。
Fix: 改为 `"距上课还有 ${countdownText(minutes)}"`。纯风格，不阻塞。

**[INFO] 提醒循环内重复解析 pausedDates**
文件： `core/domain/src/main/kotlin/com/zjh/timetable/domain/calc/ReminderPlanner.kt:53`
Issue: `WeekCalculator.pausedDatesOf(course)`（含 split + 正则解析 + runCatching）在每门课的 8 天扫描中被重复调用 8 次。课程量级下无实际影响，仅提示可提升至课程循环层级。不阻塞。

**[INFO] `Course.endMinute` 域为 1..1440 与 §9.7“一日分钟数 0..1439”的表述差异**
文件： `core/domain/src/main/kotlin/com/zjh/timetable/domain/model/Course.kt:16`
