# 智能课表 使用文档

> 宝可梦卡通风 · 本地离线 · 无账号无广告
> 适配 Android 8.0 及以上（推荐 Android 12+，提醒更准点）

---

## 一、安装

1. 把 `timetable-0.1.0-release.apk` 传到手机（微信文件传输助手 / 数据线 / 网盘均可）。
2. 手机上点开 APK → 系统提示「未知来源应用」→ 允许本次安装 → 安装。
3. 打开「智能课表」。

> 升级：直接安装新 APK 覆盖即可，**课表和配置都会保留**。

## 二、首次配置（3 分钟）

### 1. 设置学期
首页右上角 ⚙ → **学期**：
- 第 1 周起始日：选你们学校本学期第一周的**周一**（错了会导致周次判断偏差）
- 总周数：一般 16~20 周

### 2. 配置作息时间表（节次模式）
设置 → **作息时间表**：把你们学校的「第 X 节」对应时间填好（默认已预填一套常见作息，可改）。截图课表上写的「第 1-2 节」就靠它换算成具体时间。

### 3. 配置识别服务（图片导入前必做一次）
设置 → **识别服务**：
| 字段 | 填什么 |
|---|---|
| Base URL | 你的 AI 服务地址，**必须以 `/v1` 结尾**（如 `https://api.deepseek.com/v1`） |
| API Key | 该服务的密钥（只存手机本地） |
| 模型名 | 点 **「获取模型列表」**，从拉下来的列表里选一个**支持看图**的模型（名字带 vl / vision / 4o / gemini 字样的通常都可以） |

> 「获取模型列表」失败会显示服务端的具体错误，照着提示改即可（多数是 URL 少了 `/v1` 或 key 错）。

### 4. 授权通知与精确闹钟
- 首次进入首页会弹**通知权限**，允许（不收不到上课提醒）。
- 设置页如果显示「精确闹钟权限未开启」→ 点「去开启」跳系统设置打开——这保证提醒准点。
- **小米/华为等国产机**：建议在系统设置里把本应用设为「无限制省电 / 允许自启动」，否则提醒可能延迟。

## 三、导入课表（核心功能）

1. 首页 → **导入课表**。
2. 选一张**教务系统课表截图**（在相册里截好）。
3. 第一次会弹「图片将上传至你配置的识别服务」，确认继续（之后不再弹）。
4. 等待识别 → 进入**确认页**：
   - 每行是一门课：名称、星期、节次/时间、教室、老师、周次都能改
   - **标黄的行**是识别置信度低的，重点检查
   - 周次选择器：点行上的周次区域，网格点选（支持单双周、不连续周次如 1-8、10-16）
   - 顶部会提示「N 门需检查」和课程冲突 ⚠
5. 确认无误 → **确认导入** → 自动写入课表并同步小组件/提醒。

> 识别不准确的字段直接在确认页手动改就行，不必追求模型 100% 正确。

## 四、日常使用

### 桌面小组件（推荐）
长按桌面空白处 → 添加小组件/部件 → 「智能课表」：
- **2×2 下一节课**：课程名/时间/教室/倒计时，点击直达该课程编辑页
- **4×2 今日课程**：当天日期周次 + 课程列表（进行中高亮、已结束变淡），点击进首页

### 主界面
- **首页**：下一节课大卡片（含倒计时）+ 今日时间线
- **周课表**：整周网格，顶栏可切周；点空格处 **＋** 手动加课
- **课程编辑**：长按/点击课程块 → 改时间/周次/教室/颜色/单课提醒/停课日期，可删除
- **设置**：学期、作息、默认提醒提前量、识别服务、隐私说明

### 上课提醒
- 默认每节课开始前 **15 分钟**通知（标题「15 分钟后上课」，正文=课程名|时间|教室）
- 可全局改提前量，也可单门课程单独设置或关闭
- 过期不补发；非该课的周次/停课日不发

## 五、常见问题

| 问题 | 解决 |
|---|---|
| 点导入没反应/入口灰色 | 识别服务没配好，去设置页三项填齐 |
| 识别失败 HTTP 401 | API Key 错了 |
| 识别失败 HTTP 404 | Base URL 少了 `/v1` |
| 识别失败 model not found | 模型名选错了，换个支持视觉的模型 |
| 提醒没响 | 检查通知权限、精确闹钟权限、电池白名单；改课程后会自动重排 |
| 想清空重来 | 每门课可删除；识别结果不满意可在确认页「全部丢弃」 |
| 换手机 | 数据只存本机，用系统迁移/换机助手整包迁移，或在新手机重装重录 |

## 六、隐私说明

- 课表、学期、作息、API Key 全部只存在你的手机里。
- 唯一联网动作：你主动发起的**图片识别**，且每次首次使用前会明示图片将上传到你**自己配置的**识别服务。
- 无账号、无遥测、无云同步、无广告。
